# 💬 JustChat — Мессенджер для друзей

Стильный, быстрый и бесплатный приватный мессенджер для друзей.

---

## ⚡ Все реализованные фичи:
- 📹 **Кружочки (Video Notes):** Запись с фронтальной камеры в круг 1:1 с круговым таймером до 60 сек, воспроизведение на лету, полноэкранный просмотр и включение звука по тапу.
- 🎙 **Голосовые сообщения:** Запись аудио с микрофона, интерактивная звуковая волна (waveform), ускорение воспроизведения (1x / 1.5x / 2x).
- 🎵 **Музыкальный плеер:** Отправка MP3 файлов, карточка трека с обложкой, перемотка, скачивание и полноценный полноэкранный плеер с таймлайном и обложкой.
- 🐱 **Стикеры с котиками:** Отдельное всплывающее меню со стикерами милых и смешных котиков (по категориям: Ржака, Чилл, Любовь, Злость).
- 📌 **Закрепленные чаты (Pin):** Закрепление важных личных и групповых чатов на самом верху списка в 1 клик.
- 📸 **Истории (Stories):** Карусель историй с градиентным кольцом, полноэкранный просмотрщик, таймер слайдов и кнопка быстрой реакции ❤️.
- 👑 **VIP Эмодзи-статусы:** Значок статуса возле никнейма (👑, 🐱, 🔥, ⚡, 💎, 🚀, 🍕, 🎧 и др.), который виден во всех чатах, историях и профиле.
- 🔍 **Поиск по @юзернейму:** Поиск друзей по персональному `@username` и быстрое создание личных и групповых чатов.
- 🔑 **Вход по инвайт-коду:** Без платных СМС — вход по секретному коду `JUST2026`, выбор никнейма и статуса.
- ⚙️ **Настройки профиля:** Смена аватарки, статуса, описания (био) и темы.

## 📲 Как установить на телефон:

### 1. На iPhone (iOS):
1. Открыть сайт в браузере **Safari**.
2. Нажать центральную кнопку **«Поделиться»** (квадрат со стрелкой вверх ⬆️).
3. Выбрать **«На экран „Домой“»** (Add to Home Screen).
4. Всё! На рабочем столе появится иконка приложения. Оно открывается на весь экран без рамок браузера и поддерживает камеру, микрофон и уведомления.

### 2. На Android:
- **Быстрый способ (PWA):** Открыть сайт в Google Chrome ➔ нажать 3 точки ➔ **«Установить приложение»**.
- **Сборка APK файла:**
  ```bash
  npm install @capacitor/core @capacitor/cli @capacitor/android
  npx cap init JustChat com.just.chat
  npm run build
  npx cap add android
  npx cap copy
  ```

## 🌐 Бесплатный хостинг (0 рублей):
1. **Фронтенд:** Подключить к [Vercel.com](https://vercel.com) (бесплатно, дает HTTPS).
2. **Бэкенд:** [Supabase.com](https://supabase.com) (PostgreSQL, веб-сокеты и хранилище файлов).
